# 🛍️ Análisis del Comportamiento de Clientes (Store 1)

## 📋 Descripción
Store 1 buscaba profundizar su conocimiento sobre los hábitos de compra de sus usuarios para diseñar campañas de marketing mucho más efectivas y personalizadas. Para lograrlo, se ejecutó un análisis integral orientado a transformar registros transaccionales en inteligencia comercial accionable.

## 🎯 Objetivos
✅ Analizar los patrones y frecuencias de consumo de los clientes.
✅ Estandarizar y depurar la base de datos para garantizar análisis confiables.
✅ Identificar segmentos de usuarios con perfiles y comportamientos similares.
✅ Detectar consumidores de alto valor y potencial comercial.
✅ Evaluar las preferencias de compra según las categorías de productos.
✅ Respaldar estrategias de fidelización y marketing segmentado.

## 🛠️ Herramientas y Habilidades Utilizadas
* **Lenguaje:** Python
* **Entorno:** Jupyter Notebook
* **Técnicas:** Análisis de datos, Transformación de datos, Segmentación de clientes y Análisis de consumo.

## ⚙️ Metodología
1. **Depuración y normalización:** Limpieza de registros y estandarización de categorías de productos.
2. **Consolidación financiera:** Cálculo y agrupación de ingresos y gastos por usuario.
3. **Perfilamiento:** Segmentación cruzando variables demográficas y preferencias de compra.
4. **Detección de valor:** Identificación de clientes clave y creación de grupos para campañas específicas.

## 💡 Principales Hallazgos
* **Base de datos lista para negocio:** Se consolidó un conjunto de datos limpio, consistente y estructurado.
* **Segmentación clara:** Se lograron diferenciar grupos de clientes según rango de edad, intereses y nivel de gasto.
* **Clientes de alto impacto:** Se aislaron perfiles con alto potencial comercial mediante el cruce de variables demográficas y transaccionales.
* **Accionabilidad:** Las agrupaciones generadas permiten lanzar campañas de marketing dirigidas con mayor probabilidad de conversión.

## 📂 Archivo Principal
`Beta_customer_behavior_analysis_.ipynb`

## 🏁 Conclusión
Este proceso permitió obtener una radiografía clara del comportamiento de los clientes de Store 1. Tras asegurar la calidad de la información, se calcularon los ingresos generados por usuario y se definieron segmentos estratégicos basados en demografía e intereses de compra, entregando una base sólida para optimizar la retención y las decisiones comerciales de la empresa.
